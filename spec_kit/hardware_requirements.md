# Hardware Requirements

## Minimum Requirements
- **CPU**: x86_64 architecture
- **RAM**: 8 GB minimum, 16 GB recommended
- **Storage**: 150 GB free space
- **GPU**: NVIDIA GPU with CUDA support (optional but recommended)

## Recommended Specifications
- **CPU**: Multi-core processor (8+ cores recommended)
- **RAM**: 32 GB or more
- **Storage**: 500 GB+ SSD
- **GPU**: NVIDIA RTX series or higher
- **Network**: High-speed internet for downloads

## GPU Requirements
- **CUDA Compute Capability**: 8.6+ (RTX 30/40 series)
- **VRAM**: 8 GB minimum, 16 GB+ recommended
- **Drivers**: NVIDIA 525+ drivers

## Build Environment
- **Disk Space**: 150 GB for build process
- **Memory**: 16 GB RAM minimum for compilation
- **CPU**: Multi-core for parallel compilation
- **Network**: Stable internet for package downloads

## Container Requirements
- **Singularity**: 3.8+ or Apptainer 1.0+
- **FUSE**: For overlay filesystem support
- **SquashFS**: For image compression

## Remote Desktop
- **Display**: X11 forwarding support
- **Network**: Low-latency connection for VNC
- **Bandwidth**: 10+ Mbps for smooth operation
